# The Isle
Experience fierce open world survival gameplay as you attempt to stay alive on an unforgiving island inhabited by dinosaurs! Hunt. Grow. Survive.

## About
This is a proton-based server for The Isle: Evrima. This is for servers that want modding support.

## Default Ports
| Port            | Default |
| --------------- | ------- |
| Game            | 7777 (UDP) |
| Query           | 9999 (TCP) |
| RCON            | 8888 (TCP) |

## Server Requirements
> [Evrima Server Guide](https://steamcommunity.com/sharedfiles/filedetails/?id=2952501611)
- **CPU:** 4+ Cores (AMD or Intel)
- **RAM:** 8GB+ of RAM
- **Storage:** 30GB+ of storage
